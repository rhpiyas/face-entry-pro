# FaceEntryPro

### AI-Powered Biometric Attendance & Campus Intelligence System

FaceEntryPro is a proposed **AI-powered biometric attendance and campus intelligence system** developed as a Capstone Project for the **System Analysis & Design Capstone Project** course during **Summer 2026**.

The project aims to provide a smarter, faster, and more secure alternative to traditional attendance systems by combining **facial recognition, automated attendance tracking, liveness detection, smart notifications, and campus monitoring features**.

## 🚀 Project Overview

Traditional attendance systems can be time-consuming and vulnerable to problems such as proxy attendance. FaceEntryPro is designed as a centralized platform that uses **AI-based facial recognition** to automatically identify students and record their attendance.

The proposed system extends beyond attendance management by incorporating intelligent features for **campus monitoring, security, notifications, and role-based access**.

FaceEntryPro supports different types of users, including Students, Parents, Faculty Members, Security Members, and Administrators. Each user role is provided with relevant functionalities based on their responsibilities and access permissions.

## 👥 User Roles

### Student

Students can log in, complete face enrollment, view their attendance records and personal analytics, and receive notifications.

### Parent

Parents can monitor their child's attendance, view relevant attendance information, and receive notifications.

### Faculty

Faculty members can monitor student attendance, view attendance analytics, identify low-attendance students, access reports, and send notifications.

### Security

Security members can access campus monitoring features, monitor camera feeds, search recorded video, and review suspicious activities and incidents.

### Admin

Administrators can manage users, monitor system activities, access reports and analytics, manage notifications, and access broader system management features.

## 🧠 AI Technologies

The proposed system incorporates lightweight AI technologies suitable for real-time and edge-based processing.

- **MediaPipe** – Face detection and facial landmark processing
- **TensorFlow Lite** – Running lightweight AI models
- **MobileFaceNet** – Facial feature extraction and face recognition
- **MiniFASNet** – Face anti-spoofing and liveness verification
